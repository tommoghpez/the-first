# The First Project

This repository contains a small script to "uglify" a photo. The script `ugly_photo.py` adds mild noise and blur to a picture, making it look a little less flattering. It requires Pillow and NumPy.

## Usage

```
python3 ugly_photo.py input.jpg output.jpg
```

This reads `input.jpg`, applies the effect, and saves the result as `output.jpg`.
